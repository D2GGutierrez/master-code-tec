# user-api

Backend del estudiante: inscripciones, envíos, resultados y progreso. Verifica los JWT, no tiene login. Usa `app_schema`.

- Tecnología: Java 21 · Spring Boot 3.3.4 · Maven · JPA · Flyway
- Responsable: Juan Diego
- Puerto: 8081
- Estado: pendiente. Se crea en el habilitador H3 (ver `docs/habilitadores.md`).
